## 4. The gap that matters most
The controller's *own* continuity is the one thing nobody has seen survive. Workers are disposable and the ledger/tick are verified; but the controller — the only agent with the plan in its head — has run one unbroken session since September, has never compacted, never restarted, never armed a wake, and today its only compaction guard is switched off by a false heartbeat it caused itself (a hidden subagent inherits `HERDR_PANE_ID=wC:p1`, the extension's gate is pane-id-only, and the tick trusts `.ext-alive` mtime ≥ session start — so the fallback stands down while the real pi runs unreloaded code).
