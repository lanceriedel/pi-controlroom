# 019 — judge · result

Status: DONE · worker `judge` · 2026-11-17 · ~1 h 35 min · no commits (controller commits)

## Summary
`controlroom judge <NNN|brief|agent>` is a bounded, read-only LLM completion gate. It renders `prompts/judge.md`, **inlines** the brief and the result, lists the files the result links (existing, ≤ 2k lines, ≤ 8) as the only permitted reads, and runs `pi -p --mode json --tools read` (default `openai/gpt-6.1-sol`, env `CONTROLROOM_JUDGE_MODEL`, `--model`; 5-min `perl alarm`; `HERDR_*` stripped so no pane/extension side effects). The reply — a requirement table (`requirement · source quoted · PASS/PARTIAL/FAIL/N-A · evidence quoted`), `## Undeclared deviations`, `## Unsupported claims`, `## Verdict` — is written to `docs/briefs/results/NNN-judge.md` with a header and a CLI-computed `## Cost`, overwritten on re-run; `judge NNN: <verdict> ($x)` goes to `agents.log`. **`land` runs it after `check`** (`--no-judge` or D-line `judge-off` skip it) and writes ` · judge: <verdict>` into the Landed one-liner; a brief line starting with **`must:`** is hard — a `must:` row graded FAIL refuses the row (`done — judge REJECT (must: …)`, one toast) and `land --force` lands it as `judge: REJECT (forced)`. The strip shows `⚖ judge: <verdict>` next to `✓ acceptance`. Scratch proofs: ACCEPT with 12 quoted PASS rows; a silent commit named under undeclared deviations; a `must:` miss → REJECT, `land` refused, `--force` landed with the note. Live: **015 → ACCEPT WITH NOTES ($0.066)**, **014 → ACCEPT WITH NOTES ($0.053)**, and a self-judge of this result → **ACCEPT WITH NOTES ($0.101)** whose two FAILs were fixed. Three real bugs found and fixed on the way (judge file shadowed the result in `check`; judge files tripped other briefs' write-scope; a brief *named* `NNN-judge` makes the judge's output path collide with its result — it overwrote this file twice). Net **+76 lines** in `bin/controlroom` (≤ 120), 11 `(019)` markers, bash 3.2 + python3 stdlib.

## Deviations
- **`## Cost` is written by the CLI, not the model.** The brief lists `## Cost tokens/$` as template output; the model cannot know its own usage, so the template tells it to stop after `## Verdict` and the CLI appends `## Cost` from the `pi --mode json` usage events (exact, not estimated).
- **Brief and result are inlined; the `read` tool stays on** (restricted by instruction to the linked files the CLI lists). The brief says "read only the two files plus linked files ≤ 2k lines" — inlining makes the two mandatory reads free of tool round-trips and makes "no exploration" mostly structural (no bash, no grep); the read allow-list is enforced by prompt, not by sandbox (pi has no per-path read scope). The header line records how many reads happened.
- **`--here` is proven only to the `launch` call** (fake env, no Herdr workspace): the rendered brief is written and `launch judge-NNN` is invoked with `CONTROLROOM_LAUNCH_ARGS="--model <judge model>"`; I did not launch a real judge pane in this room (it would add a tab to the live room — L037 spirit). The pane worker writes the judge file itself with `## Cost: unknown — run in a pane`.
- **Cost in the `agents.log` line** (`judge NNN: <verdict> ($x)`) is the brief's own spec (Work 2) and stays; the self-judge FAILed D004 on `land` also printing `($x)` to stdout — fixed: `land` prints `judge <agent> <brief> <verdict> · <judge file>`, no `$`. The strip's LOG tail still shows the agents.log line (brief-specified).
- **`launch` changed outside the Work list** (+1 line, `CONTROLROOM_LAUNCH_ARGS` passthrough) so `judge --here` can honour "judge model never the controller model by default" — the self-judge caught that the pane path ran the room's default model.
- **`land` re-runs `check` inside `judge`** (resolution reuse, ~0.5 s) — the acceptance block runs twice per landed row. Cheaper than duplicating the resolver (≤ 120-line budget); acceptance checks are read-only by contract.
- **Three `check`/tick/judge fixes outside the brief's Work list** (B1 result-glob shadowing, B2 write-scope allow for judge files, B3 result-path collision for a brief named `NNN-judge`) — all `bin/**`, all required for the judge to coexist with `check` and with this brief.
- **Verdict rules tuned once after S1**: the first template let PARTIAL/N-A rows on unverifiable process constraints (time-box, skeleton-first) drag a good result to WITH NOTES; added "process constraints → N-A; PARTIAL/N-A don't lower the verdict". The judge still (correctly) downgraded my scratch result for a `measured above` with no measurement — that strictness is the point and was kept.
- Exit code for `NO VERDICT` is 2 (grouped with "nothing to grade") rather than 1; `land` treats it as "landing ungraded" with a ⚠.
- No `--help` arm on `land` for `--no-judge` (documented in README/SKILL instead).
- Time-box: ~1 h 35 min against 2 h; the result skeleton was written in the first 10 min, then overwritten twice by B3 (~1 h 10 and ~1 h 25) and rewritten from the session transcript.

## Still open
- **Judge drift / calibration.** gpt-6.1-sol was strict and literal (it FAILed 015 on "`(015)` markers on every new line" because the heredoc body isn't marked per line). Useful, but after a few real lands the controller may want a calibration note in the template ("markers on the enclosing block count"). Re-run `judge 015 --model <other cheap model>` to compare before tuning.
- **The strip's `⚖` chip reads whatever judge file exists** — stale after a worker edits its result until the next `judge`/`land` (`land` always re-judges, so the landed grade is current). A tick hook (re-judge on result mtime, like `accept_step`) was deliberately *not* added: D014 — never on a clock, and each run costs money.
- **Hard-requirement recall**: if the model omits a `must:` row entirely, no FAIL is detected (silent pass). Cheap fix later: the CLI knows the `must:` lines; a `must:` with no matching row → `NO VERDICT` for that line + warning.
- **Naming rule worth adopting**: never name a brief `NNN-judge` (or any CLI artefact suffix) — the guard handles it now, but the strip/`land` paths are simpler when they don't have to.
- `--here` worker epilogue is untested with a real Herdr pane (`logs/scratch/NNN-judge-brief.md` is where it renders).
- Results longer than 2000 lines are inlined truncated with a marker (the judge is told to say so) — `--here` is the intended path for those.
- Self-judge of 019 (`results/019-judge-verdict.md`) reflects the first full draft of this result; `land` will re-judge the final text and write the same path.
