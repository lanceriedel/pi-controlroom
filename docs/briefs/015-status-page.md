# 015 — status-page: a human-readable project status page, rendered from the room's files and published on events

host: local

## Objective
Add `controlroom status-page [--publish] [--snapshot]`: render `docs/status/latest.md` (+ `.html`) from the room's own files — STATUS.md (MODE, Workers, Decisions waiting, Landed, Retired), `health` (live workers), a hand-written preamble the controller owns — with brief numbers turned into GitHub links; `--publish` pushes it to GitHub Pages (always; enable Pages if absent) and to any extra publishers in `docs/status/publishers.sh` (lancedocs is one). `launch` and `land` call it automatically (opt-out by D-line). Event-driven, never on a clock. The graph-search room already does this by hand; make it a controlroom feature every room gets.

Requested by Lance via gs-controller (graph-search, wD); Lance is travelling — run autonomously, no questions back.

## Design (do this)
1. **Generator `status-page`** → writes `docs/status/latest.md` and `docs/status/latest.html`:
   - **Preamble** — `docs/status/preamble.md` is hand-written by the controller (goal/thesis/"next"), created once with a template if missing, **never overwritten**; the generated page starts with it, then a line `Generated by controlroom status-page · <date time TZ> · republished after every launch and land`.
   - **Sections from STATUS.md**: MODE line (if present) · Workers (state, brief, result link) · Decisions waiting on the human · Landed · Retired (resume commands dropped on the public page — just agent/when/reason).
   - **Live workers** from `health --json`: agent · status · brief · last write · `stuck?/spinning?` flag. **No $ / tokens** (D004) unless `--cost`.
   - **Linker**: any `NNN` or `NNN-slug` brief reference in a table cell becomes `[NNN](<repo-url>/blob/<branch>/docs/briefs/NNN-*.md)` plus ` · [result](…/results/NNN-*.md)` when the result exists, ` · [design](…/docs/design/…)` when a brief header or result names one. Repo URL from `git remote get-url origin` (ssh or https → `https://github.com/<org>/<repo>`). Relative links in STATUS.md are rewritten to absolute GitHub URLs so the page works on Pages and lancedocs.
   - `--snapshot` also writes `docs/status/YYYY-MM-DD-latest.md` (one per day, overwritten within the day); keep it opt-in, no clock.
2. **`--publish`**: `git add docs/status && git commit -m "status page <stamp>" && git pull --rebase --autostash && git push` (quiet; "unchanged" when nothing to commit). GitHub Pages: if `gh api repos/<org>/<repo>/pages` is 404 → enable with the POST above (branch from git, path `/docs`), ensure `docs/.nojekyll` and `docs/index.html` → redirect to `status/latest.html`; print the `html_url`. Then `docs/status/publishers.sh` if present and executable: each line/function is an extra publisher (ship a commented example for lancedocs: `BRAIN_ROOT=$HOME/.brain bash ~/.brain/memory-bank/personal/docs/deploy-lancedocs.sh` + copy). Verify with `curl -sI` (time-boxed 20 s; private Pages may 404 without SSO — report, don't fail). One line to `logs/publish.log`: `[stamp] status-page ghpages=pushed|unchanged|failed:<why> publishers=<n> url=<url>`. **Never push anything but `docs/status/**`, `docs/.nojekyll`, `docs/index.html`** — if other files are staged/dirty, leave them alone (commit only those paths).
3. **Hooks**: at the end of `launch` and of `land`, call `"$0" status-page --publish --quiet` **in the background with a 60 s alarm** (never block the controller; never fail the launch). Opt-out: a decision line in `docs/briefs/memory/DECISIONS.md` whose slug is `status-page-off` (grep; D-lines are the room's policy) or env `CONTROLROOM_STATUS_PAGE=0`. Log a line to `logs/agents.log` only when publish actually pushed.
4. **Docs**: README "Status page" section (what/where/how to opt out/how to add a publisher) + SKILL.md command-table rows; `prompts/controller.md`: Boot step "if `docs/status/preamble.md` is the untouched template, write the goal/thesis for this room" and "the page republishes itself after launch/land — don't do it by hand".
5. **Prove it** (write the proof table as you go):
   - mktemp scratch repo (L011) with a fake origin (bare repo) and a STATUS.md copied from this room: `status-page` renders; linker produces correct URLs; preamble survives a second run; `--snapshot` makes one dated file; `--publish` commits only `docs/status/**` and leaves a dirty unrelated file untracked; `gh`-less path degrades to "Pages: gh not available" without failing.
   - **This room, live**: run `controlroom status-page --publish` in pi-controlroom (public repo `lanceriedel/pi-controlroom`, branch `master`; Pages may already be off — enable it). Report the URL and the `publish.log` line. Then `launch` a trivial sleeper from a scratch brief? **No** — don't launch workers into the live room; instead confirm the hook path with `CONTROLROOM_STATUS_PAGE=1 controlroom land` dry logic in scratch.
   - Do **not** run `--publish` in graph-search / psd / lookbook (L037); mention in the result how gs-controller can switch from `bin/publish-latest.sh` to the built-in (`docs/status/preamble.md` ← its current goal section; `publishers.sh` ← its lancedocs step).
